## 安装

- Miao-Yunzai安装本插件请勿强制更新，强制更新后需删除重新拉取
- Miao-Yunzai需删除自带的genshin插件，Trss-Yunzai需删除外置的genshin插件

项目右上角clone选择ssh生成秘钥

然后在云崽根目录下运行
```
git clone --depth=1 git@gitcode.com:HanaHimeUnica/Mys-plugin.git ./plugins/genshin/
```

或个人设置 -> 访问令牌 -> 新建访问令牌
```
git clone --depth=1 https://用户名:访问令牌@gitcode.com/HanaHimeUnica/Mys-plugin.git ./plugins/genshin/
```

###  安装依赖

```
pnpm i
```
